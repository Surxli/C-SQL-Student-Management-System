# Student Management System (C + SQLite)

## Overview
A menu-driven console application written in C that performs CRUD operations using SQLite database.

## Features
- Insert Student
- Display Students
- Search Student by ID
- Update Student Marks
- Delete Student

## Tech Stack
- C Programming
- SQLite Database

## How It Works
User input → C program → SQL query → SQLite database → Output

## How to Run
gcc project.c -lsqlite3  
./a.out

## Key Concepts
- Database Connectivity in C
- SQL Queries (INSERT, SELECT, UPDATE, DELETE)
- Callback Function
- Primary Key Constraint
